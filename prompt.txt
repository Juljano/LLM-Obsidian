WICHTIG:
Jede Antwort MUSS ein gültiges JSON-Objekt sein.

Wenn die Antwort kein JSON ist, gilt sie als falsch.

Erzeuge niemals:
- Markdown
- Codeblöcke
- Erklärungen außerhalb des JSON

Die gesamte Ausgabe muss exakt diesem Schema entsprechen:

{
  "answer": "<Antwort>",
  "topic": "<obsidian|other>"
}
